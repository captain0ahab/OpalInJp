# OpalInJp — 日本鉱物産地探索マップ

地質データをもとに、日本国内で鉱物が採取できそうなエリアをスコアリングしてマップ上に可視化する Web アプリです。

**[→ デモを見る](https://opalinjp.onrender.com)**（Render 無料枠のため、15分無操作後はスリープします）

---

## 主な機能

### 地図操作
- 地図上の任意地点をクリック／タップして調査地点を設定
- 地名検索（Nominatim）で目的地にジャンプ
- 現在地ボタンでデバイスの GPS 位置を自動取得
- URL コピーで検索条件をそのままシェア（経緯度・半径・鉱物種が URL に保存）

### 検索・フィルタ
- 9種類の鉱物から対象を選択（または全鉱物の合計スコア）
- 調査半径を 5 / 10 / 20 / 50 / 100 km のプリセットまたはスライダーで指定

### マーカー表示
- スコア上位 80 件のポリゴンを鉱物アイコン付きマーカーで表示
- マーカーのグロー色・強度がスコアに連動（赤→橙→黄→青）
- マーカータップで詳細ポップアップ：
  - **📊 スコアの根拠** — 岩種・地質年代・断層・熱水・既知産地を自然言語で解説
  - スコア内訳（折りたたみ）
  - 形成プロセスの説明
  - Google マップリンク

### 追加レイヤー（切り替え可能）
- **⭐ 既知産地レイヤー** — 75 箇所の実績のある産地を地図上に表示。タップで産地名・信頼度・備考を確認
- **📜 伝説・逸話レイヤー** — ネット情報や昔話・伝説ベースの採取情報を 15 箇所掲載。タップで逸話を確認

### UI
- スマートフォン対応レスポンシブデザイン（モバイルはボトムドロワー形式）
- 国土地理院タイルによる日本語地名表示（ダークモード）

## スコアリングの仕組み

産総研 20万分の1地質図の 78,000 超のポリゴンに対して 5 項目を評価し合算したスコアで順位付けします。

### 1. 岩種スコア（Lithology Score）
各鉱物の母岩キーワード（`minerals_config.py` で定義）と地質図の岩種を照合し、最大 Tier 1〜4 でスコアを付与します。

| 例：砂金 | キーワード例 | スコア |
|----------|------------|--------|
| Tier 1 | デイサイト・流紋岩 | 3.0 |
| Tier 2 | 花崗岩・閃緑岩 | 2.0 |
| Tier 3 | 安山岩・変成岩 | 1.5 |
| Tier 4 | 堆積岩 | 1.0 |

### 2. 地質年代ボーナス（Age Bonus）
地層の形成年代が鉱物生成に適した時代であれば、岩種スコアに乗数を掛けます（例：砂金×新生代→×1.5）。年代不明のポリゴンはペナルティなし（×1.0）。

### 3. 断層近接ボーナス（Fault Bonus、乗算式）
断層に近接するポリゴンは熱水が循環しやすいため、スコアを乗算で増幅します。

```
断層あり: score × (1 + fault_bonus)
```

鉱物ごとに係数が異なります（翡翠・磁鉄鉱 +10%、オパール・水晶 +30%、輝安鉱 +50% など）。

### 4. 熱水変質スコア（Hydrothermal Score、鉱物別重み付き）
- 完新世・後期更新世火山岩ポリゴンとの距離で 0〜3.0 の基礎スコアを算出
  - 重複（0 m）→ +3.0 / 5 km 以内 → +2.0 / 10 km 以内 → +1.0
- OSM の温泉ノードが 5 km 以内にある場合は +1.0 を追加加算（上限 3.0）
- 各鉱物に設定された `hydrothermal_weight`（0.0〜1.0）で重み付けして個別スコアに加算
  - 翡翠（0.0）・ザクロ石（0.2）・水晶（0.3）・磁鉄鉱（0.4）・蛍石/菱マンガン鉱（0.8）・オパール/砂金/輝安鉱（1.0）

### 5. 既知産地スコア（Known Locality Score）
産総研 MRDB・鉱物同好会記録・文献をもとに **75 箇所** の既知産地を登録。ポリゴンとの距離・信頼度（1〜3）に応じてスコアを加算します（CSV バッチ処理 + Flask クエリ時リアルタイム計算）。

| 距離 | 基礎スコア |
|------|----------|
| 20 km 以内 | 3.0 |
| 50 km 以内 | 2.0 |
| 100 km 以内 | 1.0 |

## ローカルで動かす

### 必要なもの
- Python 3.11+
- `output/mineral_candidates.csv`（解析スクリプトが生成。大容量のため Git 管理外）

### セットアップ
```bash
git clone https://github.com/captain0ahab/OpalInJp.git
cd OpalInJp

python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

pip install -r requirements.txt
python app.py
```
ブラウザで `http://localhost:5000` を開きます。

### CSV の再生成（解析スクリプト）
```bash
# 地質図ポリゴンを解析して mineral_candidates.csv を生成
python analyze_minerals.py
```
> ⚠️ 全国 78,000+ ポリゴンの処理に数十分かかります。大容量ファイルは `.gitignore` で除外しています。

## ライセンスと免責事項

- 本ツールのスコアはあくまでも**地質的な可能性の参考指標**です。実際の採取可否・産出保証ではありません。
- 鉱物採取は**土地所有者・管理者の許可**を必ず得た上で行ってください。国立公園・自然保護区域内での採取は法令で禁止されています。
- 使用する地質データは広域図（20万分の1）のため、局所的な地質変化は反映されていません。
- 「伝説・逸話レイヤー」の情報はインターネット上の非公式情報や民話が含まれ、産出を保証するものではありません。
